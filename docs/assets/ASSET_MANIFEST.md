# Asset Manifest

Every important game asset should have a stable record here.

## Record Template

```yaml
asset_id:
name:
type:
path:
source:
generator_or_tool:
prompt_reference:
author:
created_date:
modified_date:
dimensions:
frame_size:
animation_frames:
directions:
format:
transparency:
intended_use:
related_entity:
status:
license_or_usage_notes:
notes:
```

## Status Values

- planned
- generating
- draft
- approved
- deprecated
- replaced
