# AI Agent Protocol

## Before Work
- Read README.md
- Read AI_CONTEXT.md
- Read PROJECT_STATUS.md
- Read ARCHITECTURE.md
- Read ROADMAP.md
- Read relevant task files
- Inspect repository state and recent history

## During Work
- Stay within task scope.
- Preserve unrelated work.
- Avoid speculative architecture.
- Do not silently delete important systems.
- Keep changes understandable.

## Before Completion
- Test affected functionality.
- Inspect changed files.
- Check for broken references.
- Update documentation.
- Record added/modified/deleted/renamed files.
- Update task status.
- Create/update ADR when required.
- Write handoff information.

## Never
- Claim tests passed when they were not run.
- Hide deletions.
- silently change fundamental architecture.
- assume old documentation is always correct.
- erase another agent's work without understanding it.

## Agent Handoff
The next agent should be able to continue without needing the previous AI conversation.
