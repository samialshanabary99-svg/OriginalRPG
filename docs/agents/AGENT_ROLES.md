# Agent Roles

Agents may specialize in:

- Architecture
- Gameplay
- Player/character systems
- Combat
- Items/inventory
- World/maps
- NPCs/quests
- UI/UX
- Audio
- Art/assets
- Tools/pipeline
- Testing/QA
- Performance
- Documentation

Only one agent is active at a time. A specialized role does not override repository-wide safety and documentation rules.
